# BAND 제공 사진 공개 편집본

- 출처: 사용자가 지정한 BAND의 교육 기록. 사용자 요청에 따라 선별·업로드한다.
- 공개 조건: 얼굴이 보이지 않는 사진만 사용. 사용자가 얼굴 영역을 잘라낸 편집본의 공개를 허용했다.
- 제작: 원본을 로컬 브라우저에 1:1로 표시하고 CSS 영역 밖을 제외한 화면을 JPEG로 캡처했다. 생성형 이미지 편집 결과는 사용하지 않았다.
- 얼굴이 있는 원본은 이 폴더에 포함하지 않는다. 원본·검토 파일은 Git에서 제외한 `tmp/band-review/`에 보관한다.
- 사진 3장은 교육 실적 3건을 의미하지 않는다. AI 관련 2장은 같은 게시물의 다른 사진이다.
- 기관명·강사 신원·교육 인정 범위·성과를 사진만으로 단정하지 않는다.
- 외부 글·원본 미디어 주소·회원 프로필·비공개 댓글은 홈페이지에 게시하지 않는다.
